# Статус возможностей

Этот файл отделяет подтверждённые пользовательские возможности от материалов,
которые нельзя считать частью текущего пользовательского контракта.

## Доступно сейчас

Подтверждено текущим кодом и тестами:

- создание и список workflow sessions;
- profile metadata и наследование профилей;
- YAML schema с фазами и transitions;
- guards, approvals и consent;
- gates `invariants`, `review`, `qa`;
- task lists и статусы задач;
- serial, parallel и serial-with-overlap task cycles;
- retry budget и решения после исчерпания попыток;
- session store с атомарным сохранением;
- TUI state widget и details dialog;
- отдельный dashboard server.

## Ограничения

- доступность конкретного перехода определяется guard и текущим состоянием;
- наличие фазы в schema не означает доступность перехода;
- dashboard запускается отдельным процессом;
- пользовательские пути и профили зависят от текущей конфигурации OpenCode;
- legacy-поля или старые документы не являются основанием для нового workflow.

## Planned или не подтверждено

Возможность не считается доступной, если она описана только в старом roadmap,
TODO или историческом документе и не подтверждается текущим runtime и тестом.
Такие материалы не следует использовать как инструкцию пользователю.

Перед добавлением новой возможности в пользовательский guide её нужно проверить
по текущему поведению и явно перевести сюда в раздел `Доступно сейчас`.
