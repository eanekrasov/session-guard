# Статус возможностей

Этот файл отделяет подтверждённые пользовательские возможности от материалов,
которые нельзя считать частью текущего пользовательского контракта.

Статус ниже относится к реализации в source repository и её тестам. В target
OpenCode project возможность доступна только после загрузки плагина и наличия
профилей в настроенном каталоге; отсутствующий `.opencode/**` в source checkout
не меняет этот статус.

## Доступно сейчас

Подтверждено текущим кодом и тестами source repository:

- создание и список workflow sessions;
- profile metadata и наследование профилей;
- YAML schema со стадиями и transitions;
- guards, approvals и consent;
- gates, объявленные профилем (в поставочном `base` — `review` и `qa`);
- task lists и статусы задач;
- serial, parallel и serial-with-overlap task cycles;
- retry budget и решения после исчерпания попыток;
- session store с атомарным сохранением;
- конфигурационный hook с `sm-*` commands, служебным агентом и синхронизацией
  profile agents;
- workflow-контекст в system prompt и при session compacting;
- TUI state widget и details dialog;
- отдельный dashboard server.

Инвариантные проверки не являются отдельным gate: их результат входит в
`task.checks` или `session.checks` и вычисляется ядром по состоянию диска.

## Ограничения

- доступность конкретного перехода определяется guard и текущим состоянием;
- наличие стадии в schema не означает доступность перехода;
- dashboard запускается отдельным процессом;
- пользовательские пути и профили зависят от текущей конфигурации OpenCode;
- `mise run smoke` требует доступный живой opencode и модель, поэтому его
  результат нельзя заменить модульными тестами;
- dashboard — source-repository utility, пока его entrypoint не входит в
  published package files;
- неподтверждённые поля и документы не являются частью пользовательского контракта.

## Planned или не подтверждено

Возможность не считается доступной, если она описана только в roadmap, TODO или справочном документе и не подтверждается текущим runtime и тестом.
Такие материалы не следует использовать как инструкцию пользователю.

Перед добавлением новой возможности в пользовательский guide её нужно проверить
по текущему поведению и явно перевести сюда в раздел `Доступно сейчас`.
